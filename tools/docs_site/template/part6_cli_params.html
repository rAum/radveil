Reference

Command line

One static binary, radveil. radveil <command> --help lists every option.

CommandPurpose
radveil auto IN OUTThe full pipeline with the built-in detector. Options: --mode, --region, --ear-mode, --mask-out, --report (JSON, - = stdout), --brain-guard, --brain-guard-mm, --brain-check, --no-verify, --skin-depth, --depth-behind, --blur-sigma, --no-eye-anchor, --yaw, --size, --threshold-frac, --threshold, --gzip-level.
radveil deface IN OUTAnonymize from given landmarks: --landmarks3d ({"points": [[x, y, z] | null, …68]}, RAS+ mm) or --landmarks (2D per view). Same --mode, --region, --ear-mode and geometry options; --qa writes renders.
radveil deskull INBrain extraction: -o stripped volume, --mask-out, --method synthstrip|classical|rvbrain, --modality, --fill, --low-memory, --report.
radveil render INPNG views plus per-view camera JSON: -o, --yaw=-20,0,20 (use = for negative angles), --pitch, --size.
radveil info INShape, spacing, orientation, datatype and affine.
radveil conform INThe grid a brain-extraction network is fed (for debugging and training data).

The mask-only escape hatch is deliberately not a CLI command: the CLI always anonymizes.

Exit status#

StatusMeaning
0Success.
1Error or refusal (no plausible face); nothing was written.
3--brain-check found modified brain voxels. The output is still written, so a batch can stop on it.

Parameter table

Geometry parameters, all optional. d is the measured inter-eye distance (~60–70 mm in adults). Python uses the name as a keyword argument, Rust as a DefaceParams field (Option<f64>), C as a struct field.

Errors & refusals

Python raises RuntimeError, Rust returns Err(String), C returns −1 with the text in radveil_last_error(), and the CLI exits with status 1. In every case nothing was modified.

Message begins withWhat it means
no plausible face in any rendered viewNo detector hit in any view, including the orientation sweep: not a head, an already-defaced scan, or a threshold that misses the skin (check a render).
face candidates did not survive validationDetections did not agree in 3D across views; typical for already-anonymized scans.
the detected face is not seen through airThe "face" lies on a field-of-view cut (for example the bottom slice of an axial slab), not on skin.
brain_check and brain_guard need the `synthstrip` featureRust only: enable the default synthstrip feature, or set brain_guard: false.
