import radveil. Functions take NIfTI paths or Volume objects and return plain dictionaries (see report dictionary). Refusals raise RuntimeError; unknown parameters or modes raise ValueError. The heavy work releases the GIL.

radveil.deface_volume(vol, mode="blur", region="face", yaws=(-20.0, 0.0, 20.0), pitch=0.0, size=512, detector="mediapipe", predictor_path=None, fallback_detector=None, fallback_brain_guard=True, verify=True, max_verify_rounds=3, verify_pitches=(0.0, -15.0), verify_effort="balanced", partial_face=False, auto_threshold=False, escalate_to_block=True, brain_check=False, brain_guard=False, brain_guard_mm=3.0, threshold_frac=0.14, threshold=None, detector_upsample=1, return_mask=False, **deface_kwargs) -> dict
function

The full pipeline on an in-memory Volume, modified in place: render, detect, validate, lift, anonymize, verify. Same code as radveil auto.

Parameters

volA Volume.
region"face" · "ears" · "face+ears"
ear_mode (keyword)Mode for the ear regions; default the same as mode. E.g. mode="adaptive", ear_mode="cut".
yaws, pitch, sizeDetection views: yaw angles and pitch in degrees, render size in pixels.
detector, predictor_path"mediapipe" (built-in), "dlib" (optional install; CC0 5-point model unless predictor_path names another), or a callable f(rgb, try_rotations) returning None, a (68, 2) array, or (array, score). Verification also runs the built-in detector whatever this is.
fallback_detector, fallback_brain_guardSame values as detector: run it when detector finds no validated face (the volume is still untouched), e.g. "dlib". That run uses the brain guard unless fallback_brain_guard=False. The report's detector and fallback_used say which succeeded.
verify, max_verify_rounds, verify_pitches, verify_effort, escalate_to_blockRe-render and re-detect after anonymizing, from every detected yaw at each pitch in verify_pitches and from a grid around the face set by verify_effort ("fast": none, "balanced": 3×3, "thorough": 5×5; speed vs. how many angles are attacked); blur modes escalate σ×1.6 per round, then an opaque fill unless disabled.
brain_guard, brain_guard_mmOpt-in: never modify the brain (extracted from the input) or anything within brain_guard_mm of it. Costs ~3 s and ~3 GB per volume.
brain_checkAlso report brain voxels modified and the clearance (report["brain"]).
partial_faceOpt-in: also handle faces cut by the field of view (an axial slab ending at the nose), which are refused otherwise.
auto_thresholdOpt-in: noisy, dim scans (e.g. infants) are retried at higher surface thresholds when no face is found.
threshold_frac, thresholdSkin surface threshold: fraction of the 99th percentile, or an absolute value. CT is detected automatically (−400 HU).
return_maskAdd the uint8 mask to the report.
**deface_kwargsear_mode and geometry overrides from the parameter table, e.g. skin_depth_mm=3.5, or the opt-ins level_face=True and spare_air=True. Unknown names raise ValueError.

Raises

RuntimeError when no validated face is found; the volume is then untouched.

radveil.anonymization_mask(vol, mode="blur", region="face", mask_path=None, yaws=(-20.0, 0.0, 20.0), pitch=0.0, size=512, detector="mediapipe", predictor_path=None, brain_check=False, brain_guard=False, brain_guard_mm=3.0, threshold_frac=0.14, threshold=None, detector_upsample=1, **deface_kwargs) -> dict
escape hatch

The region deface_volume would anonymize, as report["mask"] (uint8, the volume's grid, 1 = would be rewritten), without modifying the volume and without verification. vol is a Volume or a path; mask_path saves the mask as NIfTI with the volume's affine. See the guide.

radveil.deface_batch(inputs, output_dir=None, outputs=None, mode="blur", workers=None, executor="threads", **kwargs) -> list[dict]
function

Anonymize many files concurrently. inputs is a list of paths or a glob pattern; outputs are outputs or output_dir/<name>_defaced.nii.gz. Returns one report per input in order; a refused or failed input gets {"input", "output", "error"} instead of raising. **kwargs go to deface_auto. workers defaults to min(cpu_count, 32, len(inputs)). executor="threads" (default) runs them in this process (the Rust core releases the GIL; no __main__ guard needed); executor="processes" uses spawned worker processes, so call it under if __name__ == "__main__":. Each concurrent volume needs roughly 4–5× its voxel data in memory; with brain_guard or brain_check add ~3 GB per worker.

radveil.deskull(input_path, output_path=None, mask_path=None, gzip_level=1, **kwargs) -> dict
function

Brain extraction (skull stripping). Writes the stripped volume and/or the uint8 brain mask. Keyword arguments go to Volume.deskull: method ("synthstrip" default, "classical"), modality ("auto", "mri", "ct"), fill, low_memory; classical only: frac, robust, face, detector. Returns method, brain_volume_ml, brain_voxels, centroid_world, fill, passes, face_prior.

radveil.detect_landmarks(rgb, predictor_path=None, upsample=1, try_rotations=False, detector="mediapipe") -> ndarray | None
function

Detect a face on an RGB image (for example view["rgb"] from Volume.render) and return a (68, 2) array of pixel coordinates in the standard 68-point (iBUG) order, or None. try_rotations also searches the image rotated by 90/180/270°; coordinates stay in the original frame. With detector="dlib" and the default 5-point model, the 68 slots are filled from eyes and nose base, the mouth is inferred and the jaw slots are left out.

radveil.lift_landmarks(views, landmarks_2d) -> list
function

Lift per-view 2D landmarks to 3D through each view's position map and combine them (coordinate-wise median). Returns 68 items, each (x, y, z) in RAS+ mm or None, ready for Volume.deface.

radveil.fetch_predictor(dest="shape_predictor_5_face_landmarks.dat") -> str
function

Only for the dlib detector: download dlib's CC0-licensed 5-point landmark model (~9 MB) over HTTPS and verify pinned SHA-256 checksums. An existing dest is accepted only if its checksum matches. The dlib detector uses this file (or predictor_path / RADVEIL_SHAPE_PREDICTOR); a 68-point model is used only when passed explicitly, and warns that its training data excludes commercial use.

class radveil.Volume(path)
