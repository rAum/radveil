radveil-core is the engine behind every interface. Pure Rust, CPU-only, MSRV 1.98. Pipeline functions return Result<_, String> (a refusal or error message); file I/O returns VolumeError. Both convert into Box<dyn Error>, so ? works in main.

pub fn plan(volume: &Volume, frame: &FaceFrame, params: &DefaceParams) -> DefacePlan pub fn apply(volume: &mut Volume, frame: &FaceFrame, plan: &DefacePlan, mode: DefaceMode, blur_sigma_mm: Option<f64>) -> (DefaceReport, Array3<u8>) pub fn plan_mask(volume: &Volume, frame: &FaceFrame, plan: &DefacePlan, mode: DefaceMode) -> (DefaceReport, Array3<u8>)
building blocks

plan measures the region on the original volume (skin surface, ears). apply rewrites it; re-applying a plan never reaches beyond its first mask, which is how verification escalates safely. plan_mask rasterizes it without touching the volume. DefacePlan::face_only() restricts it to the face; face_seen_through_air() returns Some(false) when the "face" lies on a field-of-view cut. with_protected(mask) adds voxels that must never be rewritten (the brain guard uses it); DefaceReport::protected_voxels_spared counts them.

pub fn deface(volume: &mut Volume, frame: &FaceFrame, params: &DefaceParams) -> (DefaceReport, Array3<u8>) pub fn face_frame_from_landmarks(lm: &[Option<Vec3>]) -> Result<FaceFrame, String>
function

Anonymize from your own 68 world-space landmarks (plan + apply; no detection, no verification). DefaceParams derives Default: mode: DefaceMode (Blur, Adaptive, Cut, Block), ear_mode: Option<DefaceMode> (None = same as mode), region: Region (Face, Ears, FaceAndEars), and every geometry field of the parameter table as Option<f64> (None = auto). The opt-ins spare_air and level_face are bool (default false). Both enums implement FromStr ("adaptive".parse(), "face+ears".parse()).
