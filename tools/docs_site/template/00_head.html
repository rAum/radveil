Documentation · v0.1.0

RadVeil documentation

Face and ear anonymization for head MRI and CT, from Python, Rust, C/C++ or the command line. One Rust engine sits behind every interface, so the behaviour, the parameters and the reports are the same wherever you call it from. Every example on this page is run against real data before it is published.

Early release RadVeil 0.1 has been validated on a small set of scans only: the public SynthStrip evaluation set, 3D Slicer sample data and IXI. Review outputs before you share data.

Install

Python ≥ 3.9

pip install radveil
Wheels for Linux, macOS and Windows. No model download and no dlib: the face detector and brain-extraction weights are built in.

Rust ≥ 1.98

cargo add radveil-core
Pure Rust; models are embedded. Features detector, synthstrip, rvbrain are on by default.

C / C++

Download radveil-v0.1.0-<target> from GitHub Releases: include/radveil.h, shared and static lib/, and LINKING.txt.

Command line

cargo install radveil-cli or the bin/radveil binary in the release archive. No Python needed.

dlib is not a dependency. It stays available in Python as an alternative or fallback detector (pip install "radveil[dlib]"), with dlib's CC0 5-point landmark model by default (fetch_predictor()). dlib's 68-point models are never selected implicitly: their training data excludes commercial use (see legal notes).

Quick start

Load a NIfTI volume, find the face, anonymize it, verify that the face detector no longer finds it, and save. Every voxel outside the anonymized region is written back bit-exact, with the original datatype, scaling and header.

[[tabs py="py/quickstart.py" rs="rs/src/bin/quickstart.rs" c="c/quickstart.c" sh="sh/quickstart.sh"]]

On a 1 mm IXI T1 this changes about 1.1 million voxels (the air in front of the face, the nose and lips, and a few millimetres of skin). Verification then finds no face, and no brain voxel is touched.

How it works

RadVeil localizes the face the way an attacker would, then attacks its own output.

01RenderA CPU ray caster draws portrait views, with a 3D world position for every pixel.
02DetectA 2D face detector (built-in MediaPipe models) finds 68 landmarks per view.
03LiftLandmarks become 3D points; views must agree in 3D or they are rejected.
04RewriteA skin-deep region in the face frame is blurred, cut or filled.
05VerifyThe result is re-rendered and re-detected; detection escalates the mode.
