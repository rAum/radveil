Reference

C / C++

A plain C ABI in radveil.h, usable from C, C++ and anything with a C FFI. The face detector is built in (radveil_deface_auto); hosts with their own detector pass landmarks to radveil_deface.

Conventions & linking#

  • Errors: int32_t functions return 0 on success and −1 on error or refusal; radveil_last_error() gives the message (thread-local; it holds the most recent failure on that thread).
  • Arrays: C order (nx, ny, nz), k fastest. Masks are uint8_t[nx*ny*nz], caller-allocated. World coordinates are RAS+ mm.
  • Ownership: every RadveilVolume* from radveil_volume_load or radveil_volume_from_array is freed with radveil_volume_free. Optional pointers may be NULL.
  • Parameters: call radveil_deface_params_init before overriding fields: a zero-initialised struct means 0 mm, not "auto".

lifecycle

load and from_array return NULL on error. from_array copies data (nx·ny·nz floats) and a row-major 4×4 voxel→RAS+ affine. save keeps the header, datatype and scaling; gzip_level 0–9 (1 = fast default).

int32_t radveil_deface_auto(RadveilVolume *vol, const char *mode, const char *region, const RadveilDefaceParams *params, const RadveilEarParams *ear_params, uint8_t verify, uint8_t brain, uint8_t *mask_out, RadveilAutoReport *report);
pipeline

Detect, validate, anonymize and verify, in place. verify: RADVEIL_VERIFY_OFF (0), RADVEIL_VERIFY_ON (1, default effort: the detection views plus a 3×3 grid around the face), RADVEIL_VERIFY_FAST (detection views only) or RADVEIL_VERIFY_THOROUGH (5×5 grid). mode: "blur", "adaptive", "cut", "block"; region: "face", "ears", "face+ears". Returns −1 and leaves the volume untouched when no validated face is found. params, ear_params, mask_out and report may be NULL. brain takes the flags RADVEIL_BRAIN_CHECK (report brain voxels modified) and RADVEIL_BRAIN_GUARD (never modify anything within 3 mm of the brain; the report's brain_guard_spared counts the region voxels it kept), combined with |, or 0. Example: the quick start.

int32_t radveil_anonymization_mask(const RadveilVolume *vol, const char *mode, const char *region, const RadveilDefaceParams *params, const RadveilEarParams *ear_params, uint8_t brain, uint8_t *mask_out, RadveilAutoReport *report);
escape hatch

The region radveil_deface_auto would rewrite, into mask_out (required), without modifying the volume and without verification; report->base.voxels_changed counts the voxels that would change and the verification fields are −1. C++ example in the guide.

your landmarks

Anonymize in place from points: 68×3 doubles in the standard 68-point (iBUG) landmark order, world RAS+ mm, NaN for a missing landmark. No detection and no verification. _region adds the region selector and ear parameters; _regions also takes ear_mode, a separate mode for the ears (NULL = same as mode), e.g. "adaptive" face and "cut" ears. Example in the guide.

structs

A negative or NaN field means auto (scaled from the inter-eye distance). The _init functions set every field to auto; override what you need afterwards. Meanings are in the parameter table.

int32_t radveil_render(const RadveilVolume *vol, double yaw_deg, double pitch_deg, uint32_t size, float threshold_frac, float threshold_abs, uint8_t *rgb, float *pos, uint8_t *flags);
function

One orthographic surface view. Outputs are caller-allocated and optional: rgb size·size·3 bytes, pos size·size·3 floats (world position per pixel, NaN = miss), flags size·size bytes (0 miss, 1 hit, 2 hit on the volume boundary). threshold_abs = NAN selects the automatic threshold. Lift your own 2D detections through pos.

int32_t radveil_deskull(RadveilVolume *vol, const char *method, const char *modality, double frac, uint8_t use_face, uint8_t strip, uint8_t low_memory, float fill, uint8_t *mask_out, RadveilDeskullReport *report);
function

Brain extraction. method: "synthstrip" or "classical"; modality: "auto", "mri", "ct". strip = 1 sets non-brain voxels to fill in place (NaN = 0 for MRI, air for CT). mask_out (1 = brain) and report may be NULL.
