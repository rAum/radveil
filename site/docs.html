Documentation · v0.1.0

RadVeil documentation

Face and ear anonymization for head MRI and CT, from Python, Rust, C/C++ or the command line. One Rust engine sits behind every interface, so the behaviour, the parameters and the reports are the same wherever you call it from. Every example on this page is run against real data before it is published.

Early release RadVeil 0.1 has been validated on a small set of scans only: the public SynthStrip evaluation set, 3D Slicer sample data and IXI. Review outputs before you share data.

Start

Install

Python ≥ 3.9

pip install radveil
Wheels for Linux, macOS and Windows. No model download and no dlib: the face detector and brain-extraction weights are built in.

Rust ≥ 1.98

cargo add radveil-core
Pure Rust; models are embedded. Features detector, synthstrip, rvbrain are on by default.

C / C++

Download radveil-v0.1.0-<target> from GitHub Releases: include/radveil.h, shared and static lib/, and LINKING.txt.

Command line

cargo install radveil-cli or the bin/radveil binary in the release archive. No Python needed.

dlib is not a dependency. It stays available in Python as an alternative or fallback detector (pip install "radveil[dlib]"), with dlib's CC0 5-point landmark model by default (fetch_predictor()). dlib's 68-point models are never selected implicitly: their training data excludes commercial use (see legal notes).

Start

Quick start

Load a NIfTI volume, find the face, anonymize it, verify that the face detector no longer finds it, and save. Every voxel outside the anonymized region is written back bit-exact, with the original datatype, scaling and header.

quickstart.py
import radveil

report = radveil.deface_auto("t1.nii.gz", "t1_defaced.nii.gz", mode="adaptive")
print(report["voxels_changed"], "voxels changed;", report["residual_detections"], "faces left")
quickstart.rs
use radveil_core::{deface_auto, AutoParams, DefaceMode, DefaceParams, MediaPipeDetector, Volume};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut vol = Volume::load("t1.nii.gz")?;
    let params = AutoParams {
        deface: DefaceParams {
            mode: DefaceMode::Adaptive,
            ..Default::default()
        },
        ..Default::default()
    };
    let report = deface_auto(&mut vol, &mut MediaPipeDetector::default(), &params)?;
    println!(
        "{} voxels changed, faces left: {:?}",
        report.deface.voxels_changed, report.residual_detections
    );
    vol.save("t1_defaced.nii.gz")?;
    Ok(())
}
quickstart.c
#include <stdio.h>
#include "radveil.h"

int main(void) {
    RadveilVolume *vol = radveil_volume_load("t1.nii.gz");
    if (!vol) { fprintf(stderr, "load: %s\n", radveil_last_error()); return 1; }

    RadveilAutoReport rep;
    if (radveil_deface_auto(vol, "adaptive", "face", NULL, NULL,
                            /*verify=*/1, /*brain=*/RADVEIL_BRAIN_CHECK, NULL, &rep) != 0) {
        fprintf(stderr, "refused: %s\n", radveil_last_error());  /* volume untouched */
        radveil_volume_free(vol);
        return 2;
    }
    printf("%llu voxels changed, %d faces left, %lld brain voxels touched\n",
           (unsigned long long)rep.base.voxels_changed, rep.residual_detections,
           (long long)rep.brain_voxels_modified);
    if (radveil_volume_save(vol, "t1_defaced.nii.gz", 1) != 0)
        fprintf(stderr, "save: %s\n", radveil_last_error());
    radveil_volume_free(vol);
    return 0;
}
quickstart.sh
radveil auto t1.nii.gz t1_defaced.nii.gz --mode adaptive --report report.json

On a 1 mm IXI T1 this changes about 1.1 million voxels (the air in front of the face, the nose and lips, and a few millimetres of skin). Verification then finds no face, and no brain voxel is touched.

Start

How it works

RadVeil localizes the face the way an attacker would, then attacks its own output.

01RenderA CPU ray caster draws portrait views, with a 3D world position for every pixel.
02DetectA 2D face detector (built-in MediaPipe models) finds 68 landmarks per view.
03LiftLandmarks become 3D points; views must agree in 3D or they are rejected.
04RewriteA skin-deep region in the face frame is blurred, cut or filled.
05VerifyThe result is re-rendered and re-detected; detection escalates the mode.

Volumes & coordinates#

  • A volume is a 3D voxel array plus a 4×4 voxel→world affine. World coordinates are NIfTI RAS+ millimetres: +x right, +y anterior, +z superior.
  • Any storage orientation works (RAS, LPS, PIR, oblique). If the stored orientation is wrong, a six-direction sweep finds the face anyway and the report says orientation_sweep: true.
  • Arrays are indexed (i, j, k) in voxel order. Masks come back on the same grid as the input, so mask[i, j, k] refers to data[i, j, k]. In C they are flat, C-order, k fastest.
  • Intensities are read with the NIfTI scaling applied; saving writes them back with the original datatype, scl_slope/scl_inter and header.

Modes & regions#

ModeWhat happens inside the region
blurGaussian blur (σ auto-scaled, ~10 mm). Gross morphology survives. The default.
adaptiveGradient-weighted averaging: the stronger the facial feature, the heavier the kernel. Recommended.
cutBackground fill: ~0 on MRI, air on CT (never water-density 0 HU).
blockOpaque constant fill. Also the final escalation step of verification.

3D Slicer’s public “MRHead” sample, radveil auto with default settings (tools/make_site_images.py). On this head verification escalated blur and adaptive twice; verified cut still read as a face and was escalated to a fill, so it is shown with verification off.

Regions: face (default), ears or face+ears. The pinna is a biometric identifier too. No landmark model emits ear points, so each pinna is found by measuring the head surface, and the report says per ear whether it was detected or fell back to an anthropometric window. Verification is skipped for ears alone, since the face legitimately remains. ear_mode sets a different mode for the ears in the same pass, e.g. adaptive face and cut ears (recommended: blur leaves 10–16% of the pinna surface in place).

Safety model#

Refuses rather than guesses

No plausible face (non-head data, already defaced), candidates that fail 3D shape consensus, or a "face" on a field-of-view cut: nothing is modified and an error is raised.

Skin-deep

The region follows the measured skin: the air in front of the face, nose and lips, and skin_depth_mm (~4.5 mm) of skin, chosen to stay above the skull.

Verified

The output is re-rendered and re-detected from every detected yaw, also at 0° and −15° pitch (verify_pitches), from a grid of angles around the face (verify_effort: fast, balanced, thorough), and always by the built-in detector too. Blur escalates (σ×1.6 per round), then an opaque fill. Escalations reuse the first region, so they never cut deeper.

Bit-exact elsewhere, brain guard on request

Only voxels inside the exported mask change. The opt-in brain_guard extracts the brain and never modifies anything within 3 mm of it.

On the public SynthStrip evaluation set (582 scans with expert brain masks), RadVeil processed 201 and refused the rest. The region touched the brain mask on none of them (closest 1.3 mm), and no face was re-detected after adaptive anonymization, at 1.25 s per scan. With the opt-in brain guard no scan was touched (closest change 3.6 mm), for one brain extraction more: about 4 s and 3.2 GB per scan. Header metadata (names, IDs, dates) is not scrubbed: that stays with your de-identification pipeline.

Auto parameters#

Every geometric parameter is optional. Left unset, it is scaled from d, the measured distance between the eyes, so adults, children and phantoms need no tuning. Set a value in millimetres to override it; the report always contains the resolved values. The full list, with the name in each language, is in the parameter table.

Anonymize a file#

The file-to-file call takes every pipeline option. Here it also removes the ears (with their own mode, ear_mode), writes the mask of changed voxels, and saves before/after renders for review. The report is plain JSON-ready data.

file.py
import json
import radveil

report = radveil.deface_auto(
    "t1.nii.gz", "t1_defaced.nii.gz",
    mode="adaptive",
    region="face+ears",           # the pinna is biometric too
    ear_mode="cut",               # its own mode: blur leaves part of the pinna
    mask_path="t1_mask.nii.gz",   # exactly which voxels changed (uint8 NIfTI)
    qa_dir="qa",                  # before/after renders for review
)
for roi in report["rois"]:
    print(roi["label"], roi["voxels"], roi.get("detected"))
json.dump(report, open("report.json", "w"), indent=2)  # JSON-ready

The Rust pipeline is the same call as the quick start; set DefaceParams { region: Region::FaceAndEars, ear_mode: Some(DefaceMode::Cut), .. } and AutoParams { return_mask: true, .. }, then read report.mask. AutoReport implements serde::Serialize.

Pass "face+ears" as region and a uint8_t buffer of nx·ny·nz bytes as mask_out to radveil_deface_auto (one mode for all regions; a separate ear mode needs your landmarks and radveil_deface_regions).

file.sh
radveil auto t1.nii.gz t1_defaced.nii.gz --mode adaptive --region face+ears --ear-mode cut \
  --mask-out t1_mask.nii.gz --report report.json

Arrays & DICOM#

Nothing requires a file. Build a volume from any float32 array and its voxel→RAS+ affine: a DICOM series read with pydicom or SimpleITK, an imaging application’s volume, or raw data. The volume is modified in place. For uploads and object stores, Volume.from_bytes(data) parses .nii/.nii.gz content and vol.to_bytes() encodes the result, with no temporary file.

memory.py
import nibabel as nib
import numpy as np
import radveil

img = nib.load("t1.nii.gz")  # or a DICOM series read with pydicom / SimpleITK
vol = radveil.Volume.from_array(np.asarray(img.dataobj, dtype=np.float32), img.affine)
report = radveil.deface_volume(vol, mode="adaptive")  # modifies vol in place
nib.save(nib.Nifti1Image(vol.data(), img.affine), "t1_defaced.nii.gz")
print(report["views_detected"], "views,", report["verify_rounds"], "verification rounds")

Volume::from_array(data: Array3<f32>, affine: Mat4) (a row-major 4×4 f64 array), then the same deface_auto call; the result is in vol.data.

radveil_volume_from_array(nx, ny, nz, data, affine) copies your float buffer (C order) and a row-major 4×4 affine; read the result back from your own pipeline or save it with radveil_volume_save.

The CLI works on NIfTI files; convert DICOM first (for example with dcm2niix).

Region only: process it yourself#

An API-only escape hatch. anonymization_mask runs detection, validation, the safety refusals and (optionally) the brain check, then returns the exact region deface_auto would rewrite. The volume is not touched. Escalations in deface_auto reuse the same region, so this is the final mask.

region.py
import radveil

report = radveil.anonymization_mask("t1.nii.gz", mask_path="t1_region.nii.gz")
mask = report["mask"]  # uint8 (nx, ny, nz), 1 = voxel deface_auto would rewrite
print(mask.shape, int(mask.sum()), report["voxels_changed"])
region.rs
use radveil_core::{anonymization_mask, AutoParams, MediaPipeDetector, Volume};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let vol = Volume::load("t1.nii.gz")?;
    let report = anonymization_mask(
        &vol,
        &mut MediaPipeDetector::default(),
        &AutoParams::default(),
    )?;
    let mask = report
        .mask
        .expect("anonymization_mask always returns the mask");
    let n = mask.iter().filter(|&&m| m == 1).count();
    println!(
        "{n} voxels would be rewritten (report: {})",
        report.deface.voxels_changed
    );
    // Save it on the same grid, e.g. for review in a viewer.
    Volume::from_array(mask.mapv(f32::from), vol.affine).save("t1_region.nii.gz")?;
    Ok(())
}
region.cpp
#include <cstdio>
#include <memory>
#include <stdexcept>
#include <vector>
#include "radveil.h"

// RAII ownership for the opaque volume handle.
struct VolumeFree { void operator()(RadveilVolume *v) const { radveil_volume_free(v); } };
using Volume = std::unique_ptr<RadveilVolume, VolumeFree>;

static void check(int32_t rc) {
    if (rc != 0) throw std::runtime_error(radveil_last_error());
}

int main() {
    Volume vol{radveil_volume_load("t1.nii.gz")};
    if (!vol) throw std::runtime_error(radveil_last_error());

    uint64_t dims[3];
    radveil_volume_shape(vol.get(), dims);
    std::vector<uint8_t> mask(dims[0] * dims[1] * dims[2]);  // C order, k fastest

    RadveilDefaceParams params;
    radveil_deface_params_init(&params);  // every field "auto" ...
    params.skin_depth_mm = 4.0;           // ... then override what you need

    RadveilAutoReport rep;
    check(radveil_anonymization_mask(vol.get(), "adaptive", "face", &params, nullptr,
                                     /*brain=*/0, mask.data(), &rep));
    std::printf("%llu voxels would be rewritten; the volume is untouched\n",
                (unsigned long long)rep.base.voxels_changed);
}
region.sh
# The CLI always anonymizes. The region-only escape hatch is API-only;
# --mask-out writes the region alongside the anonymized output.
radveil auto t1.nii.gz t1_defaced.nii.gz --mode adaptive --mask-out t1_region.nii.gz
Nothing is verified in this mode The mask says where RadVeil would anonymize, not that your processing of it hides the face. Check the result: render it and run detect_landmarks on the views, or run deface_auto on your output and expect a refusal.

Brain check & brain extraction#

Two opt-in safety options, sharing one brain extraction from the input (SynthStrip, pure Rust, ~3 s): brain_guard never modifies the brain or anything within 3 mm of it, and brain_check reports how many brain voxels were modified and how close the change came. Brain extraction is also available on its own.

brain.py
import radveil

rep = radveil.deskull("t1.nii.gz", "t1_brain.nii.gz", mask_path="t1_brain_mask.nii.gz")
print(f"brain {rep['brain_volume_ml']:.0f} ml")

# brain_guard: never modify the brain or anything within 3 mm of it (opt-in,
# ~3 s per volume); brain_check: report what happened, from the same extraction.
report = radveil.deface_auto("t1.nii.gz", "t1_defaced.nii.gz", brain_guard=True, brain_check=True)
assert report["brain"]["voxels_modified"] == 0, report["brain"]
print("brain untouched, margin", report["brain"]["margin_mm"], "mm")
brain.rs
use radveil_core::{brain_mask, deface_auto, AutoParams, DeskullParams, MediaPipeDetector, Volume};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Brain extraction on its own (SynthStrip, pure Rust).
    let vol = Volume::load("t1.nii.gz")?;
    let (brain, rep) = brain_mask(&vol, &DeskullParams::default())?;
    println!(
        "brain {:.0} ml, {} voxels",
        rep.brain_volume_ml,
        brain.iter().filter(|&&b| b == 1).count()
    );

    // Or around anonymization: the guard never modifies the brain (opt-in,
    // ~3 s per volume); the check reports on it from the same extraction.
    let mut vol = Volume::load("t1.nii.gz")?;
    let params = AutoParams {
        brain_guard: true,
        brain_check: true,
        ..Default::default()
    };
    let report = deface_auto(&mut vol, &mut MediaPipeDetector::default(), &params)?;
    let check = report.brain.expect("brain_check was requested");
    assert_eq!(check.voxels_modified, 0, "anonymization touched the brain");
    Ok(())
}

Pass RADVEIL_BRAIN_GUARD | RADVEIL_BRAIN_CHECK as brain to radveil_deface_auto (see the quick start) and read report.brain_voxels_modified; extract the brain with radveil_deskull.

brain.sh
radveil deskull t1.nii.gz -o t1_brain.nii.gz --mask-out t1_brain_mask.nii.gz

# --brain-guard: never modify the brain or anything within 3 mm of it (~3 s).
# --brain-check: exit status 3 if a brain voxel was modified (output still written).
radveil auto t1.nii.gz t1_defaced.nii.gz --brain-guard --brain-check

Your own face detector#

The built-in detector (MediaPipe BlazeFace + Face Mesh, embedded) needs no setup. To use another model, give the pipeline 68 landmarks in the standard 68-point (iBUG) order on each rendered view; validation and verification still run. In C, hosts supply 68 world-space points directly.

detector.py
import numpy as np
import radveil

def my_detector(rgb: np.ndarray, try_rotations: bool):
    """Return None, a (68, 2) array in the 68-point (iBUG) order, or (array, score)."""
    return radveil.detect_landmarks(rgb, try_rotations=try_rotations)

report = radveil.deface_auto("t1.nii.gz", "t1_defaced.nii.gz", detector=my_detector)
print(report["detector"], report["views_detected"])
detector.rs
use radveil_core::{deface_auto, AutoParams, Detection, FaceDetector, Volume};

/// Any 2D landmark model can drive the pipeline: return 68 points in
/// the standard 68-point (iBUG) order (pixel coordinates of the rendered view), or None.
struct MyDetector;

impl FaceDetector for MyDetector {
    fn detect(
        &mut self,
        rgb: &[u8],
        w: usize,
        h: usize,
        _try_rotations: bool,
    ) -> Result<Option<Detection>, String> {
        let _ = (rgb, w, h); // run your model here
        Ok(None)
    }
}

fn main() {
    let mut vol = Volume::load("t1.nii.gz").expect("load");
    match deface_auto(&mut vol, &mut MyDetector, &AutoParams::default()) {
        Ok(r) => println!("{} voxels changed", r.deface.voxels_changed),
        Err(refusal) => eprintln!("refused, volume untouched: {refusal}"),
    }
}
landmarks.c
#include <math.h>
#include <stdio.h>
#include "radveil.h"

/* Your own detector: 68 landmarks (standard 68-point order), world RAS+ mm.
 * Here they are read from "points.txt" (one "x y z" per line, "nan nan nan"
 * for a missing point). To lift 2D detections yourself, render with
 * radveil_render: its pos output maps every pixel to a world position. */
int main(void) {
    double pts[68 * 3];
    FILE *f = fopen("points.txt", "r");
    if (!f) { perror("points.txt"); return 1; }
    for (int i = 0; i < 68 * 3; i++)
        if (fscanf(f, "%lf", &pts[i]) != 1) pts[i] = NAN;
    fclose(f);

    RadveilVolume *vol = radveil_volume_load("t1.nii.gz");
    if (!vol) { fprintf(stderr, "%s\n", radveil_last_error()); return 1; }
    RadveilReport rep;
    if (radveil_deface(vol, pts, "adaptive", NULL, NULL, &rep) != 0) {
        fprintf(stderr, "%s\n", radveil_last_error());
        radveil_volume_free(vol);
        return 1;
    }
    printf("%llu voxels changed (no verification: check the result)\n",
           (unsigned long long)rep.voxels_changed);
    radveil_volume_save(vol, "t1_defaced.nii.gz", 1);
    radveil_volume_free(vol);
    return 0;
}

Pass 68 world-space points as JSON: radveil deface in.nii.gz out.nii.gz --landmarks3d points.json (see step by step).

Whatever detector found the face, verification also attacks the output with the built-in one. In Python, detector="dlib" selects the optional dlib detector (pip install "radveil[dlib]" and fetch_predictor()): dlib's CC0 5-point model by default, eyes and nose base measured, mouth inferred, jaw unused. fallback_detector="dlib" instead keeps the built-in detector and processes only the scans it rejects, with the brain guard on (fallback_brain_guard=True); the report's fallback_used says which ran. dlib's research-only 68-point models are used only when passed as predictor_path, with a license warning.

Cohorts#

deface_batch runs workers volumes at a time (default min(cpu_count, 32, n)) on threads in one process: the Rust core releases the GIL, so threads scale like processes and share one copy of the detector models. executor="processes" isolates each volume in a spawned worker instead (then call it under if __name__ == "__main__":). Refused or failed inputs are reported, not raised.

batch.py
import radveil

# Threads in this process by default (the Rust core releases the GIL);
# executor="processes" isolates each volume in a worker process instead.
reports = radveil.deface_batch("cohort/*.nii.gz", output_dir="defaced", mode="adaptive", workers=2)
for r in reports:
    print(r["input"], r.get("error") or f"{r['voxels_changed']} voxels")

Call deface_auto per file from your own thread pool; each thread needs its own MediaPipeDetector.

Call radveil_deface_auto per volume; errors are thread-local (radveil_last_error).

batch.sh
mkdir -p defaced
for f in cohort/*.nii.gz; do
  radveil auto "$f" "defaced/$(basename "$f" .nii.gz)_defaced.nii.gz" --mode adaptive \
    || echo "$f: refused or failed (exit $?)" >&2
done

Handling refusals#

A refusal means RadVeil found no face it trusts and changed nothing. Treat it as an item for human review, never as processed. Anonymizing an already-anonymized scan is the classic case:

refusal.py
import radveil

try:
    radveil.deface_auto("t1_defaced.nii.gz", "twice.nii.gz")
except RuntimeError as refusal:  # nothing was written
    print("refused:", str(refusal)[:60])

Step by step#

Every stage is exposed: render views with a position map, detect 2D landmarks, lift them to 3D, anonymize. This path skips shape-consensus validation and verification, so prefer deface_volume unless you need the parts.

steps.py
import radveil

vol = radveil.Volume("t1.nii.gz")
views = [vol.render(yaw_deg=yaw) for yaw in (-20, 0, 20)]
landmarks = [radveil.detect_landmarks(v["rgb"]) for v in views]  # (68, 2) or None
points = radveil.lift_landmarks(views, landmarks)                # 68 x (x, y, z) | None
report = vol.deface(points, mode="adaptive")
vol.save("t1_defaced.nii.gz")
print(report["voxels_changed"], "voxels changed")

render_view → your detector → RenderView::world_at → face_frame_from_landmarks → deface; see the Rust reference.

landmarks.c
#include <math.h>
#include <stdio.h>
#include "radveil.h"

/* Your own detector: 68 landmarks (standard 68-point order), world RAS+ mm.
 * Here they are read from "points.txt" (one "x y z" per line, "nan nan nan"
 * for a missing point). To lift 2D detections yourself, render with
 * radveil_render: its pos output maps every pixel to a world position. */
int main(void) {
    double pts[68 * 3];
    FILE *f = fopen("points.txt", "r");
    if (!f) { perror("points.txt"); return 1; }
    for (int i = 0; i < 68 * 3; i++)
        if (fscanf(f, "%lf", &pts[i]) != 1) pts[i] = NAN;
    fclose(f);

    RadveilVolume *vol = radveil_volume_load("t1.nii.gz");
    if (!vol) { fprintf(stderr, "%s\n", radveil_last_error()); return 1; }
    RadveilReport rep;
    if (radveil_deface(vol, pts, "adaptive", NULL, NULL, &rep) != 0) {
        fprintf(stderr, "%s\n", radveil_last_error());
        radveil_volume_free(vol);
        return 1;
    }
    printf("%llu voxels changed (no verification: check the result)\n",
           (unsigned long long)rep.voxels_changed);
    radveil_volume_save(vol, "t1_defaced.nii.gz", 1);
    radveil_volume_free(vol);
    return 0;
}

C / C++

A plain C ABI in radveil.h, usable from C, C++ and anything with a C FFI. The face detector is built in (radveil_deface_auto); hosts with their own detector pass landmarks to radveil_deface.

Conventions & linking#

  • Errors: int32_t functions return 0 on success and −1 on error or refusal; radveil_last_error() gives the message (thread-local; it holds the most recent failure on that thread).
  • Arrays: C order (nx, ny, nz), k fastest. Masks are uint8_t[nx*ny*nz], caller-allocated. World coordinates are RAS+ mm.
  • Ownership: every RadveilVolume* from radveil_volume_load or radveil_volume_from_array is freed with radveil_volume_free. Optional pointers may be NULL.
  • Parameters: call radveil_deface_params_init before overriding fields: a zero-initialised struct means 0 mm, not "auto".

Errors & refusals

Python raises RuntimeError, Rust returns Err(String), C returns −1 with the text in radveil_last_error(), and the CLI exits with status 1. In every case nothing was modified.

Message begins withWhat it means
no plausible face in any rendered viewNo detector hit in any view, including the orientation sweep: not a head, an already-defaced scan, or a threshold that misses the skin (check a render).
face candidates did not survive validationDetections did not agree in 3D across views; typical for already-anonymized scans.
the detected face is not seen through airThe "face" lies on a field-of-view cut (for example the bottom slice of an axial slab), not on skin.
brain_check and brain_guard need the `synthstrip` featureRust only: enable the default synthstrip feature, or set brain_guard: false.
