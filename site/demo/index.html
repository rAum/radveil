Anonymize a head scan in your browser

Drop a NIfTI file. RadVeil renders the head, finds the face with an embedded face detector, blurs or removes it, and then attacks its own output with the same detector until no face is found. This is the same Rust code as the command-line tool, compiled to WebAssembly.

Your file stays on this computer. Nothing is uploaded.
Drop a .nii or .nii.gz file or click to choose one 3D head MRI or CT
