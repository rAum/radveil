# Security policy

**This project not actively maintained or funded, it is best effort.**

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on
[rAum/radveil](https://github.com/rAum/radveil/security). Do not open a
public issue.

Please include the affected version or commit, the artifact (Python wheel,
CLI or C library), and steps to reproduce.

This project not actively maintained or funded, it is best effort.

## Supported versions

Fixes go into the latest release. There is no long-term-support branch.

## Dependencies and SBOM

Each release includes CycloneDX SBOMs, and dependencies are checked against
the RustSec advisory database every week. See [docs/sbom.md](docs/sbom.md).
